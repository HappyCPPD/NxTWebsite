How the team solved each challenge at Kaspersky CTF 2026. Root cause first, then the exploit. 9 solves, 736 points, 69th in the Asia regional league.

  • pwn 182 pts

    SlopGateQEMU escape

    The hardened SlopGate PCI device is a decoy. The serial console still drops to the QEMU monitor, and `migrate "exec:..."` runs a command on the host.

    kaspersky{I_th1nk_w3_b0th_g0t_dumb3r_wh1l3_s0lvin6_this_t4sk} read
  • AI 89 pts

    LumberjackML / OOB read

    An ONNX-to-native compiler never bounds-checks `feature_idx`. A negative index reads the `FLAG` env pointer off the stack, one float at a time, through a tree-classifier oracle.

    kaspersky{3d87a80c-9ab7-4c35-aeb4-f64bbae9bb44} read
  • misc 77 pts

    chroot-bronzechroot escape

    Root inside a bare chroot. Ship an ELF with `printf` octal escapes, run it via `ld.so` to dodge the missing `+x`, then the classic `chroot`/`chdir("..")` walk-out.

    kaspersky{fb30b3a6-ff28-4698-b023-bfb73c4bbf63} read
  • rev 74 pts

    awasmsafeWASM + Electron

    The password check is a WASM RC4 whose key is derived from the page's own source and CSP hash, gated behind ~56 anti-Node fingerprint checks. Run the real Electron renderer, then solve the RC4 algebraically.

    kaspersky{w4sm_3lectrif1ed_7d19ae15} read
  • misc 64 pts

    chroot-silversandbox escape

    `SOCAT_PPID=1` gives it away: the jailer lives outside the jail. Build a musl PIE, upload it with all-3-digit octal `printf`, run via the musl loader, and escape through a saved root fd.

    kaspersky{a9f61e72-504f-4d36-8094-be8147e05f42} read
  • crypto 50 pts

    Sudokryptcustom cipher

    The Feistel and sudoku layers are keyless and publicly invertible. Two design leaks recover both secret permutations, and a shared block counter exposes the spectral keystream as a degree-56 linear recurrence.

    kaspersky{D4mn_1m_s0_c00l!!_1_c4n_d0_sud0ku_n0w_st4cy_t0t4lly_g01ng_t0_pr0m_w1th_m3} read
  • crypto 50 pts

    Shiny Sweetie Curveelliptic curve

    A fresh random curve every round, only x-coordinates leaked. X-only addition identities plus a resultant-and-GCD trick recover the secret prime, then `a`, `b`, and the step point.

    kaspersky{g4mbl1ng_1s_b4d_t4k3_c4r3_0f_y0urs3lf} read
  • rev 50 pts

    biblockerSIGSEGV "TPM"

    The "Trusted Potato Module" is a SIGSEGV handler that hands back AES key material derived from the fault address via XTEA. Re-implement the CRC and XTEA statically. The key is `target_key XOR mask`.

    kaspersky{s1gn4l5_pr0v1d3d_tPm_k1nd4_sus} read
  • crypto 50 pts

    CensoredHNP / lattice

    Each Schnorr signature ships a "diagnostic" blob whose XOR masks are computable from public data. Unmask it for ~16 bits of nonce per signature, then solve the Hidden Number Problem by lattice reduction.

    kaspersky{N0w_4ll_tH3_4nsW3rs_4r3_1n_y0ur_h4nds!!!!} read
