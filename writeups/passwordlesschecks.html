PasswordlessChecks Replaying an Xbox controller into RPG Maker

forensics
flag MetaCTF{Nbu8W32GsvbSNSNS}

#1. What the artifacts are

passwordless-checks.zip ships two files:

  • NotAGame.exe - an InstallShield CAB that installs an RPG Maker VX game (RGSS202E), title "NamingSimulator".
  • capture.pcapng - a USBPcap trace of an Xbox controller (VID:PID 045e:0b12, GIP protocol): 484 frames, 205 input reports.

The game is a joke wrapper: it exists only to type something in, and the pcap is the recording of the controller typing it.

#2. Extract and read the game

NotAGame.exe unpacks (InstallShield) to a VX project. Game.rgss2a is RGSSAD v1:

  • magic key 0xDEADCAFE, running key k = k*7 + 3 (mod 2^32)
  • data XORed with the key's 4 bytes, advancing every 4 bytes
  • gotcha: v1 has no stored offset field - a file's data follows its size field contiguously (a parser that assumes an offset reads one giant "file")

#3. Decode the controller, replay the input

In the GIP input reports the buttons word is at bytes 4-5:

bit button
0x10 A
0x40 X
0x100 / 0x200 / 0x400 / 0x800 Up / Down / Left / Right

Replaying the 88 button events through the VX name-grid state machine (cursor moves ±10 for U/D and ±1 for L/R with the game's wrap rules; X confirms the current cell's char) produces the 16-character string - which fills max_char exactly and is the flag body.

#5. Gotchas

  1. tshark is AppArmor-confined under /home/... - copy the pcap to /tmp to read it.
  2. RGSSAD v1 has no stored offset field (see §2) - the classic parser bug here.
  3. wine + Xvfb was used to validate the game logic against the real engine (the bundled umeplus font matters for the exact grid).
