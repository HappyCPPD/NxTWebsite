LetMeOut Jinja2 sandbox escape via NFKC

pwn
flag hiCTF{__^_^__n0rm4l1z3_b3f0r3_y0u_tru5t__>_<___77331508e2}

Category: web · Files: letmeout.zip (source in ext/) · Flag format: hiCTF{} LIVE INSTANCE required for the real flag: ncat --ssl <host> 1337.

#The jail (ext/jail.py, abridged)

So: one {{ expression }}, ≤170 chars, ≤3 distinct letters, only two filters (rich/plain), no globals, sandboxed attribute access.

#Vulnerability 1 - NFKC smuggles the attribute name past the guard

jinja2.sandbox.SandboxedEnvironment.getitem (3.1.6):

is_safe_attribute rejects attr.startswith("_"). But attr here is str(argument), i.e. the NFKC-normalised string, while the guard is applied to the raw argument. A Tag whose raw text starts with U+FF3F FULLWIDTH LOW LINE (\uff3f, NFKC -> _) therefore renders as __class__ for getattr while passing startswith("_") and is_internal_attribute.

#Vulnerability 2 - wrap_str_format hands out an unsandboxed function

getitem returns self.wrap_str_format(value) before the safety check. For any str/str subclass, ["format"] (a non-underscore name, so the guard would allow it anyway) returns a freshly-built Python wrapper function defined inside jinja2/sandbox.py. Its __globals__ is the jinja2.sandbox module namespace → ["__builtins__"] → ["breakpoint"] → pdb, whose stdin is the raw socket: from there every restriction (length / letters / sandbox) is gone.

#Payload (≤168 chars for all ten possible filter names)

  • every attribute/string letter is written as a 3-digit octal escape (\137\143…), which the jinja lexer decodes with .encode("ascii","backslashreplace").decode("unicode-escape") - octal contains only digits, so it contributes zero alphabetic characters;
  • the only literal letters are those of the chosen rich filter name (all are ?uff ⇒ {x,u,f} = 3 distinct letters);
  • lit __globals__ is "\uff3f_\147l\157\142\141l\163__" (leading U+FF3F + octal).

The real flag is the hiCTF{...} line; the other three names are decoys ("not the flag you're looking for").

#Reproduce

exploit.py probes all ten filter names ({{0|name}} prints 0 iff the name exists), tries each present name (only the rich one yields a Tag, so only it enters pdb), drives pdb, and prints the /flags/* contents.

#Verified

python3 exploit.py remote letmeout-10ca6df92e4f.chall.hiddeninvestigations.net 1337 →

FLAG: hiCTF{__^_^__n0rm4l1z3_b3f0r3_y0u_tru5t__>_<___77331508e2} (the flag name itself names the bug: "normalize before you trust" - getitem normalised for getattr but guarded the raw value).

Offline (python3 exploit.py local) returns the image's placeholder hiCTF{fake_flag_for_local_testing} + 3 decoys, which proves the read path independent of the real flag.
