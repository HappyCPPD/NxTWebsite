Soul Forge two-time pad and crib dragging

crypto 100 pts
flag OWASP{s0ul_f0rge_pr1m3s_4r3_n3v3r_r4nd0m}

TL;DR

Two ciphertexts encrypted with the same keystream (two-time pad). XOR the ciphertexts to cancel the keystream, then crib-drag the XOR to recover both plaintexts. The flag was in the longer message.

#1. Reused keystream

The attachment contains two hex-encoded ciphertexts:

Length Hex
T1 57 bytes 5945b2affe943fcc07714e6fdf6a4bc1...
T2 77 bytes 5945b2affe943fcc07714e6fc16a5bc0...

The first 12 bytes are identical (5945b2affe943fcc07714e6f). Since both messages were encrypted with the same keystream, identical plaintext bytes produce identical ciphertext bytes - so both plaintexts share a 12-character prefix. This is the classic two-time pad scenario:

#3. Crib dragging

Starting from the identical prefix, cribs were tested against X to find English text in one message and leet-speak flag content in the other.

Shared prefix (positions 0-11): Both messages start with Soul Forge: (12 bytes, all-zero XOR confirms identical text).

Positions 12-17: XOR bytes 1e 00 10 01 04 13 match the word pair Secret / Messag. The XOR at position 18 is 0x7f, which forces a punctuation/special character pair (_ / space).

#4. Completing the flag

The recovered flag text ends at ...r4n (position 56) - the overlap boundary. T2 has 20 more bytes beyond T1's length, but those can't be decrypted from the pair alone since there's no corresponding T1 data and the keystream doesn't repeat.

The partial r4n strongly suggests r4nd0m ("random"), giving:

#Key takeaways

  • Two ciphertexts sharing a prefix = reused keystream. XOR them to cancel the key material.
  • Crib dragging on P1 XOR P2: guess a word in one message, XOR it against X, check if the result is plausible text in the other message.
  • The 0x7f XOR byte at position 18 was a constraint that narrowed the character pair to _ / space - useful for bootstrapping the crib drag.
  • When the flag extends beyond the overlap, context and domain knowledge ("primes are never random") fill the gap.
