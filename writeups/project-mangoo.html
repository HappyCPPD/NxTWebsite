#Controlled OOB buffer

The token line is read with fgets(buf,0x80) into a stack buffer inside the OOB window at rsi-0xE0 (verified with a marker: idx=-8 read back MARKERZZMARKERZZ). So ~63 bytes AFTER the 64-hex token are attacker-controlled AND OOB-readable. With a fake descriptor placed there, idx∈{-9..-6} makes VULN 3 read our pointer and call an address of our choosing with rcx pointing into our own controlled bytes.

#Where the flag is

MANGOO_ROOT_KEY is copied (strncpy, 0x100) into a separate 0x4000 heap buffer ([rbx+0x50], likely the 0x7f0000 pointer seen at idx -1 Ref); the labels/descriptors buffer is [rbx+0x18] (= 0x7e0000, channel-0 Ref). The key is never printed or used - it can only be recovered by a read primitive on that buffer. Ingest writes [rbx+0x18] only (confirmed: pattern-fill did NOT affect channels or the sync descriptor), so corrupting descriptors does not clobber the key.

#Full exploit

Ingest is NOT needed. Everything is done with one crafted auth line + Sync Channel idx=-8.

Layout facts (stable - Wine, no on these regions):

  • allocA (labels/descriptors, [rbx+0x18], ingest target) = 0x7e0000
  • allocB (MANGOO_ROOT_KEY, [rbx+0x50]) = 0x7f0000 (leaked as idx=-1's Ref)
  • auth line buffer (fgets(0x80)) base = 0x31f9d0 (= rsi-0xF0, rsi=0x31fac0)

Steps:

  1. Auth bypass (VULN 1) and craft the line as: 64-char token hex, then at offset 0x48 p64(0x31fa10) (fake descriptor pointer) and at 0x50 p64(PIVOT).
  2. Sync Channel with idx = -8 (VULN 2 + 3): slot = rsi-0x100+0x58 = BASE+0x48. rdx = *(slot) = 0x31fa10 ; rdx = *(rdx+0x10) = *(0x31fa20) = PIVOT -> cmp fails (!= 0x140019cb0) -> call rdx, with rcx = &slot.
  3. PIVOT @ 0x1400016d0: mov rax,[rcx] (= 0x31fa10) ; mov rsp,rax ; add rsp,0x18 ; ret -> RSP = 0x31fa28, i.e. inside our own line on the real stack (pivoting into the heap instead makes Wine's msvcrt crash, so the stack pivot matters).
  4. chain (written at line offset 0x58): pop rcx ; ret (0x14000bd60) / 0x7f0000 / local printf wrapper 0x140018c90 (takes the format string in rcx, so passing the key buffer prints it directly) / exit (0x1400183e0).
  5. Output: the key is printed.
