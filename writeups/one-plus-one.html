because the p * q terms cancel. Each later entry has norm around 2**512 * 2**444 = 2**956, far below the lattice determinant, so finds v.

Pitfall

The scale K is the whole game. Too large and LLL misses the target vector; too small and the target is not short enough to be first. K = 2**440 fits this parameter set (rbit = 444, pbit = 512); other noise sizes need a different exponent.
