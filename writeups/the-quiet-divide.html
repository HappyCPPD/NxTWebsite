#Chain

  1. Triage - http + quic + a little dns. The real payload is an "archive vault" HTTP API plus two QUIC v1 sessions (udp/4433, udp/4434).

  2. Keylogs from escrow shares - POST /v3/escrow bodies carry two diagnostic shares (slot A / slot B, 760 B each). shareA XOR shareB == the escrowed TLS keylog (sha256 matches keylog_sha256) → two keylog files.

  3. Decrypt the QUIC sessions with tshark -o tls.keylog_file:…. Payloads are mb-quic-observation/3 objects (signed by ARCH-14 resp. REC-14).

  4. Reference implementation - GET /v10/sdk returns text/x-python: the interop lib (evidence_components, archive_key, decrypt_archive, unmask_fragment, transaction_material_commit, final_key, seal_aad, decrypt_seal).

  5. Reassemble the codec - ranged GETs rebuild the pulse-codec_7.7.0 ELF (sha matches /v2/manifest). A PLS2 frame = the udp/9002 payload from ARCH-14; decode_pls2() → seq 10450910 / queue 23 / load 71.
