13 writeups

  • NeuropetAndroid backup, hidden DEX, native core rev An Android backup unpacks to a Tamagotchi APK whose skin.dat is really an LCG-XORed DEX. Calling the native core directly, without JNI or the watchdog, gives up four "neuron" payloads that concatenate into the flag.
  • KuMir Behind the WallSSRF through an avatar URL web Forum breadcrumbs point at an internal checker API. The avatar URL field fetches server-side, so a wrong answer submitted through it makes the checker report the expected answer, which is the flag.
  • The Missing ArchiveRSA with leaked high bits, Coppersmith crypto Four RSA-2048 instances each leak the top 518 bits of one prime. Coppersmith with a 4-bit brute force factors all four, and the last 8 bytes of each plaintext join into the flag.
  • ShellBreachNTFS alternate data stream, LNK-derived key forensics A dynamic VHD holds an NTFS volume that is all decoy except one 44-byte alternate data stream. The XOR key is the odd-one-out ObjectID tail in a shortcut file's TrackerDataBlock.
  • Ventilator303Galaksija cassette audio to Z80 misc A 1987 radio broadcast turns out to be a Galaksija home computer tape. Demodulating the WAV gives a TAP file, and reversing the Z80 code loaded at 0x8000 recovers the flag.
  • Unreal DuckUE5 client, hidden cheat codes rev An Unreal Engine 5.7 duck game only sends the flag after a route with three trigger volumes, each wanting a secret 5-letter code. The codes brute force offline from hashes in the client, then a scripted run under Wine collects the flag image.
  • StecademiaOAuth open redirect, PKCE bypass web An open redirect in the OAuth state handling leaks the victim's authorization code. PKCE doesn't help when the attacker generated the challenge, so the stolen code redeems into a teacher session.
  • Faded TraceGeolocating a castle photo osint A photo covered in stickers, cropped clean and run through Yandex, matches the Jankowski House. The answer is the camera position, worked out from the zoom and angle of the shot.
  • Vintage BankIDOR via predictable UUIDv1 web Safe deposit boxes are keyed by UUIDv1 tokens with a fixed MAC, fixed clock sequence and whole-second timestamps. A public ledger leaks the rental time, so the target box's UUID can be rebuilt directly.
  • LockpickiCE40 bitstream keystream device misc An iCE40 bitstream decompiles to a keystream generator with a 32-bit key comparator. The key itself is a decoy. The flag is what the device prints, once the data bus bit order is derived from the ROM bytes it XORs in.
  • Easier Than It SeemsUAC triage to a VM-packed implant forensics A UAC archive from a never-rebooted web box leads to the malware still running. It hides behind an aegis_vm layer and anti-debug checks, so an LD_PRELOAD shim fakes TracerPid and the flag comes out at the comparison call.
  • KommunalochkaWildcard DNS room takeover web Rooms are addressed as username subdomains on nip.io. Swapping the username in Burp for upravdom, the building manager, opens the manager's room and the flag.
  • Zero ReportSelf-referential hash invariant crypto The auditor accepts any (a, b) on the line (1 - h)a + hb = 0 mod 2^127 - 1, where h hashes the submitted source. The program can compute H(SOURCE) itself, so a = h, b = h - 1 always passes.
