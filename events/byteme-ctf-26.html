25 writeups

  • Hidden SoulLSB stego in an 80x80 PNG forensics A plain ASCII flag sits in the least-significant bits of every R, G and B value. zsteg finds it at b1,rgb,lsb,xy, and a short Pillow script confirms the same bytes.
  • Soul WorldLSB stego, two independent extractions forensics Another RGB LSB image, this time with the flag at the very start of the bitstream. zsteg and a from-scratch row-major extractor produce byte-identical output.
  • The Last SoulLSB stego carrying base64 forensics The LSB layer is itself a base64 string. An incompressible 19 KB file for an 80x80 image is the tell, and decoding the extracted text gives the flag.
  • Soul in the ShadowsLSB, base64 and a VORMIR XOR forensics Nothing is appended to the PNG, but the pixels carry a base64 string in their LSBs. The decoded bytes are ciphertext, and the key VORMIR is teased by the image's tEXt comment and the title.
  • Invisible Signala message drawn as a scatter plot forensics A matplotlib scatter plot hides 40 double-size markers among hundreds of noise points. Calibrating the axes from the gridlines and reading each y-value as an ASCII code spells a leetspeak sentence.
  • Broken Soul Vaulthex payload in a mislabelled .bin forensics The .bin file is plain text, with guard values around a hex line. Decoding the middle line and checking it against the OWASP pattern picks the valid recovered block.
  • Soul Memoryprocess extract with a decoy hint forensics The memory dump is a small key=value extract. A vault_hint line points past the cache key, but the flag is just carried in the data field.
  • Echoes of the Snaphex in a DNS TXT field forensics The capture summary shows one stream with a long even-length hex string in a TXT record. Piping it through xxd -r -p gives readable leetspeak.
  • Echoes of Vormir: Mem-1timestamp from a Windows memory image forensics The first memory forensics warm-up asks when the dump was taken. Volatility 3 windows.info reports the SystemTime from KUSER_SHARED_DATA, which is the flag.
  • Echoes of Vormir: Mem-2a renamed PowerShell in the process list forensics One process does not belong: SoulHunt_7F31 spawned from powershell.exe. Its command line and dumped strings show it is a renamed copy of PowerShell.
  • Echoes of Vormir: Mem-3a painted image cached in memory forensics The hint says the answer is something seen. Filescan on the dump lists a cached Sacrifice.png, and dumping it shows a wallpaper with the flag painted on top in black text.
  • Echoes of Vormir: Mem-4a leftover fragment in command history forensics A fragment survives outside the tidy mapped files. Console and heap leftovers in the raw dump carry a hex-encoded OWASP flag from the same family, which decodes with xxd. The value is a reconstruction, not confirmed against the scoreboard.
  • Echoes of Vormir: Mem-5browser history in the memory dump forensics The last trace is browser activity. Carving the mapped History object shows Bing searches for FTK Imager and winpmem, and the dump holds the matching flag in hex and UTF-16LE form.
  • Echoes of Vormir: Mem-6the forgotten expedition note forensics A small expedition.txt note is carved from memory. Its artifact reference is a hex string that decodes straight to the flag.
  • The Last Memory of Vormirreversed speech and a WAV trailer forensics The WAV speaks backwards and says the key is sacrifice. 213 bytes sit past the declared RIFF end as hex pairs, and XORing them with that key yields the riddle.
  • SacrificePCAP, FTP files and nested archives forensics A PCAP's FTP streams carry a JPEG whose comment holds a password and whose embedded ZIP holds comms.bin. Peeling gzip, bzip2 and gzip off to a tar leaves one oversized log with a base64 flag.
  • Soul Forgetwo-time pad and crib dragging crypto Two ciphertexts share a keystream and the first 12 bytes match. XORing them and dragging cribs from the shared prefix recovers both plaintexts.
  • Vormir Common ModulusRSA common modulus attack crypto The same message is encrypted under one modulus with e=65537 and e=65539. The extended Euclidean algorithm gives a and b with a*e1 + b*e2 = 1, so m = c1^a * c2^b mod n.
  • Double Troubleshared RSA prime and an XOR key crypto The gcd of the two moduli is a shared prime, which decrypts both. One plaintext is base64 and the other is the XOR key GAMORA that unlocks it.
  • Soul's Whisperstack-built strings in an ELF rev Strings shows four overlapping 8-byte fragments that nearly spell the flag. Reading soul_stone() shows the real layout and the gate string soul, so the naive concatenation is a trap.
  • Soul's Weaknessgets() overflow to a win function pwn An unstripped, non-PIE binary with no canary and a gets() into a 32-byte buffer. 40 bytes of padding and the address of soul_stone hijacks the return, verified against the remote.
  • Return to Winret2win with a 10-byte buffer pwn A classic gets() overflow into hello()'s 10-byte buffer. 18 bytes of padding reach the return address, which is pointed at win().
  • Red Skull's TrailGitHub history to a PNG trailer osint A riddle names Vormir-616, whose GitHub repo has a tampered record. The git history reveals an image rename, and base64 trailing the PNG's IEND chunk gives the username.
  • Level 0: First FragmentQR code split into 3x3 tiles misc A WinZip AES archive opens with the password OWASP. Its nine shuffled tiles are slices of one QR code, rebuilt by locating finder patterns and validating the decode.
  • Level 1: Shattered Memoriesrotated 4x4 QR tiles misc Sixteen binary tiles are shuffled and rotated. Edge-signature matching with backtracking, validated by a QR decoder, assembles the code.
