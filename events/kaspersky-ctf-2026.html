  • SlopGateQEMU escape pwn The hardened SlopGate PCI device is a decoy. The serial console still drops to the QEMU monitor, and `migrate "exec:..."` runs a command on the host.
  • LumberjackML / OOB read AI An ONNX-to-native compiler never bounds-checks `feature_idx`. A negative index reads the `FLAG` env pointer off the stack, one float at a time, through a tree-classifier oracle.
  • chroot-bronzechroot escape misc Root inside a bare chroot. Ship an ELF with `printf` octal escapes, run it via `ld.so` to dodge the missing `+x`, then the classic `chroot`/`chdir("..")` walk-out.
  • awasmsafeWASM + Electron rev The password check is a WASM RC4 whose key is derived from the page's own source and CSP hash, gated behind ~56 anti-Node fingerprint checks. Run the real Electron renderer, then solve the RC4 algebraically.
  • chroot-silversandbox escape misc `SOCAT_PPID=1` gives it away: the jailer lives outside the jail. Build a musl PIE, upload it with all-3-digit octal `printf`, run via the musl loader, and escape through a saved root fd.
  • Sudokryptcustom cipher crypto The Feistel and sudoku layers are keyless and publicly invertible. Two design leaks recover both secret permutations, and a shared block counter exposes the spectral keystream as a degree-56 linear recurrence.
  • Shiny Sweetie Curveelliptic curve crypto A fresh random curve every round, only x-coordinates leaked. X-only addition identities plus a resultant-and-GCD trick recover the secret prime, then `a`, `b`, and the step point.
  • biblockerSIGSEGV "TPM" rev The "Trusted Potato Module" is a SIGSEGV handler that hands back AES key material derived from the fault address via XTEA. Re-implement the CRC and XTEA statically. The key is `target_key XOR mask`.
  • CensoredHNP / lattice crypto Each Schnorr signature ships a "diagnostic" blob whose XOR masks are computable from public data. Unmask it for ~16 bits of nonce per signature, then solve the Hidden Number Problem by lattice reduction.
